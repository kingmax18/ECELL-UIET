# User Data & Content Integrity Policy

## CRITICAL USER RULE
**Never invent, synthesize, or add unverified or placeholder data.**
- Do NOT generate fictional blog posts, articles, or author attributions.
- Do NOT invent or add fake names, founder profiles, testimonials, awards, or partners.
- Do NOT fabricate metrics, event statistics, attendee counts, or funding amounts.
- When preparing the code for production, review, or push:
  - Use ONLY authentic data explicitly provided or approved by the user.
  - If data has not been provided yet, leave the array empty (`[]`) or use a clean minimal empty state rather than inventing mockup entries that the user would have to manually find and delete.
